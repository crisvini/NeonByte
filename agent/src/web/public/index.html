Format and device limits

The Windows agent composes the GIF at 240 × 240 and encodes RGB565 colors with palettes, row compression, and frame differences. NBIF v2 supports up to 60 frames; legacy NBIF v1 remains limited to 20. Animations are limited to 30 seconds and 2,359,296 encoded bytes. Older firmware may report a 20-frame capacity.

The panel validates dimensions, frame count, duration, size, and SHA-256 before replacement. The existing animation will be removed before sending; a failed or cancelled transfer cannot preserve it. The converted file must fit with a 32 KiB reserve.

DEVICE LINKDevice connection settings＋

Device access is disabled until enabled. HTTP is unencrypted; use a trusted network.

Pairing credentials stay in the Windows credential manager. For new credentials, use node agent/dist/main.js configure-device in a foreground terminal.

SERVICE BAYFirmware maintenance＋

Copy the reviewed firmware.bin and matching manifest.json into %LOCALAPPDATA%\NeonByte\firmware-inbox. Preparation reads only this fixed folder. Experimental test candidates require a separate confirmation and do not grant production approval.
