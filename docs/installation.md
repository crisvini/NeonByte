# Instalação

**Estado:** PENDENTE. A Etapa 1 não entrega agente executável, simulador distribuído nem firmware.

No momento, é possível instalar as ferramentas de validação do repositório com npm ci e executá-las com npm run check. Isso não instala nem configura o NeonByte no computador ou no relógio.

Instruções de instalação para Windows 11 e Fedora serão documentadas depois que o agente existir. Instruções do dispositivo dependem da identificação do hardware, de um backup/restauração testáveis e de autorização explícita para qualquer gravação.
